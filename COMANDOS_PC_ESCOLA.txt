============================================================
TABERNA CANTINA - COMANDOS PARA O PC DA ESCOLA
Repositorio: https://github.com/XxDanteexX/taberna-cantina
Usuario GitHub: XxDanteexX
============================================================

COMO USAR
1. No VS Code: Terminal > New Terminal > escolha Command Prompt.
2. O prompt deve ser parecido com: C:\Users\...>
   Se aparecer PS C:\...>, voce esta no PowerShell. Troque para Command Prompt.
3. Copie apenas o que estiver entre as linhas --- INICIO --- e --- FIM ---.
4. As linhas REM sao comentarios. Pode copiar junto; o cmd ignora.
5. Tenha Git e Python 3.12 ou superior instalados.

RESUMO
1. Clonar o repositorio.
2. Criar a venv, instalar dependencias, criar o banco, popular o cardapio
   e criar o login de desenvolvimento.
3. Rodar o servidor e abrir o link.

============================================================
PASSO 1 - CLONAR O REPOSITORIO
============================================================
--- INICIO ---
REM Vai para a pasta Downloads
cd /d "%USERPROFILE%\Downloads"

REM Clona o repositorio para a pasta taberna-cantina
git clone https://github.com/XxDanteexX/taberna-cantina.git
--- FIM ---

Se pedir login do GitHub, conclua antes de seguir.
Se a pasta taberna-cantina ja existir, apague ou renomeie antes.

============================================================
PASSO 2 - CRIAR A VENV, INSTALAR E PREPARAR O BANCO
============================================================
--- INICIO ---
REM Entra na pasta do projeto
cd /d "%USERPROFILE%\Downloads\taberna-cantina"

REM Se o manage.py estiver em uma subpasta, entra nela
if not exist manage.py cd taberna-cantina-main

REM Confere se o manage.py esta na pasta atual
dir manage.py
if not exist manage.py echo ERRO: manage.py nao encontrado. Ajuste a pasta antes de continuar.

REM Cria a venv (ambiente isolado do projeto)
python -m venv .venv

REM Garante o pip dentro da venv
.venv\Scripts\python.exe -m ensurepip --upgrade

REM Atualiza o pip
.venv\Scripts\python.exe -m pip install --upgrade pip

REM Instala o Django e as demais dependencias
.venv\Scripts\python.exe -m pip install -r requirements.txt

REM Cria as tabelas do banco db.sqlite3
.venv\Scripts\python.exe manage.py migrate

REM Cria as 5 categorias e os 39 produtos
.venv\Scripts\python.exe manage.py seed_dados

REM Cria o usuario dev_taberna e imprime o link de login
.venv\Scripts\python.exe manage.py dev_login
--- FIM ---

IMPORTANTE: copie o link que aparecer. Ele expira em 1 hora.
O dev_login nao pergunta nome nem senha.
Nao rode createsuperuser; ele e que pergunta nome, e-mail e senha.

============================================================
PASSO 3 - RODAR O SERVIDOR
============================================================
--- INICIO ---
REM Inicia o servidor local. Este comando deixa o terminal ocupado.
.venv\Scripts\python.exe manage.py runserver
--- FIM ---

Abra no navegador:
http://127.0.0.1:8000/

Depois abra o link do dev_login que voce copiou.
Para parar o servidor: Ctrl + C.

Admin do Django:
http://127.0.0.1:8000/admin/

============================================================
SE O PYTHON NAO FOR RECONHECIDO
============================================================
Troque apenas esta linha do Passo 2:

python -m venv .venv

por:

py -m venv .venv

O restante do Passo 2 continua igual.
Se o Python abrir a Microsoft Store, instale o Python do site python.org
e marque a opcao "Add python.exe to PATH".

============================================================
SE O LINK EXPIRAR
============================================================
Pare o servidor com Ctrl + C e rode:

--- INICIO ---
REM Gera um novo link de login
.venv\Scripts\python.exe manage.py dev_login
--- FIM ---

Copie o novo link e rode de novo:

.venv\Scripts\python.exe manage.py runserver

============================================================
SE A PORTA 8000 ESTIVER OCUPADA
============================================================
--- INICIO ---
REM Usa a porta 8001
.venv\Scripts\python.exe manage.py runserver 8001
--- FIM ---

Abra http://127.0.0.1:8001/ e troque a porta do link para 8001.

============================================================
SE O MANAGE.PY NAO FOR ENCONTRADO
============================================================
--- INICIO ---
REM Procura o manage.py dentro da pasta clonada
dir /s /b "%USERPROFILE%\Downloads\taberna-cantina\manage.py"
--- FIM ---

Entre na pasta mostrada e rode o Passo 2 de novo.
Normalmente a pasta correta e:
C:\Users\SEU_USUARIO\Downloads\taberna-cantina

============================================================
SE O GIT DISSER "REPOSITORY NOT FOUND"
============================================================
- Confirme que voce esta logado na conta XxDanteexX.
- Confirme se a URL esta exatamente:
  https://github.com/XxDanteexX/taberna-cantina.git
- O repositorio e privado; use o navegador ou um token do GitHub.

============================================================
CONFERIR SE ESTA TUDO CERTO (OPCIONAL)
============================================================
--- INICIO ---
REM Roda os testes automatizados
.venv\Scripts\python.exe manage.py test
--- FIM ---

O esperado e terminar com "OK" e 36 testes passando.

============================================================
DICAS
============================================================
- Nao rode createsuperuser. O dev_login ja cria o superusuario dev_taberna.
- Se o seed disser "0 criados" e "39 ja existentes", esta correto.
- Para testar cartao, use 4242 4242 4242 4242.
- Em DEBUG=True, qualquer numero de 13 a 19 digitos tambem e aceito.
- A pasta .venv e o arquivo db.sqlite3 nao vao para o GitHub.
- Eles ficam dentro da pasta do projeto e sao recriados no PC da escola.
- Se o terminal for PowerShell, use .\.venv\Scripts\python.exe
  ou troque para Command Prompt.

============================================================
NO FINAL DA AULA
============================================================
1. Pare o servidor com Ctrl + C.
2. Feche o VS Code.
3. Exclua a pasta taberna-cantina de Downloads, se quiser.

Se quiser guardar os dados de teste, copie o arquivo db.sqlite3
para outro lugar antes de excluir a pasta.
